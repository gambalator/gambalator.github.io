# Как Gambalator считает победителей

## Расчёт гамбашаров

1. В расчёте участвуют только активные донаты. По умолчанию они обрабатываются в порядке добавления: сначала старые, затем новые, хотя на странице список показан в обратном порядке. Ручное изменение порядка записей также меняет порядок их расчёта.
2. Все суммы переводятся в рубли. Затем донаты по очереди заполняют гамбашар до заданной суммы, например `5000.0 RUB`.
3. Если донат пересекает границу гамбашара, нужная часть завершает текущий гамбашар, а остаток переходит в следующий.
4. В каждом завершённом гамбашаре части донатов одного пользователя складываются. Пробелы по краям и регистр никнейма не учитываются: `Alex`, ` alex ` и `ALEX` считаются одним никнеймом.
5. Побеждает никнейм с наибольшей суммарной частью донатов в этом гамбашаре.
6. Если максимальные суммы двух или более участников равны, победителем показывается `Chat`.
7. Один никнейм может победить в нескольких гамбашарах. Незавершённый гамбашар победителя не получает, а его донаты остаются активными.

### Пример 1: два обычных гамбашара

Сумма гамбашара — `5000.0 RUB`:

1. `name1 — 3000.0 RUB`
2. `name2 — 1000.0 RUB`
3. `name3 — 1000.0 RUB`
4. `name4 — 4000.0 RUB`
5. `name5 — 1000.0 RUB`

Первый гамбашар: `name1 3000.0 + name2 1000.0 + name3 1000.0`. Победитель — `name1`.

Второй гамбашар: `name4 4000.0 + name5 1000.0`. Победитель — `name4`.

### Пример 2: перенос остатка

Сумма гамбашара — `5000.0 RUB`:

- `name1 — 4000.0 RUB`
- `name2 — 2000.0 RUB`

Из доната `name2` берётся `1000.0 RUB`, чтобы завершить гамбашар. Оставшиеся `1000.0 RUB` переходят в следующий гамбашар и остаются активными. Победитель завершённого гамбашара — `name1` с вкладом `4000.0 RUB`.

Если большой донат участвует сразу в нескольких завершённых гамбашарах, его никнейм может победить в каждом из них. Например, при донатах `name1 — 1000.0 RUB` и `name2 — 9000.0 RUB` победителем обоих гамбашаров будет `name2`.

### Пример 3: ничья

При донатах `Alice — 2500.0 RUB` и `Bob — 2500.0 RUB` максимальные вклады равны. Результат гамбашара — `Chat`, сумма победителя — `2500.0 RUB`.

## Валюты

- Базовая валюта расчёта — `RUB`.
- Курсы по умолчанию: `1 EUR = 100.0 RUB`, `1 USD = 85.5 RUB`.
- Рублёвый донат не конвертируется.
- Донат в валюте пересчитывается по формуле: `сумма × сохранённый курс`.
- Результат конвертации округляется до одного знака после запятой в рублях. Все границы гамбашаров и сравнение вкладов используют это округлённое значение.
- При нажатии `РАССЧИТАТЬ` для активных донатов в USD и EUR используются последние сохранённые курсы.

### Пример конвертации

`100.0 USD × 85.5 = 8550.0 RUB`.

При сумме гамбашара `5000.0 RUB` из этого доната создаётся использованная часть `5000.0 RUB`, а остаток `3550.0 RUB` остаётся активным для следующего расчёта.

После использования сумма и применённый курс фиксируются: последующее изменение курса не меняет историю. Если валютный донат вообще не был использован, потому что полного гамбашара ещё нет, он остаётся в исходной валюте и при следующем расчёте пересчитывается по актуальному сохранённому курсу.

Для точности приложение хранит денежные значения как целое количество десятых долей, поэтому расчёты границ и ничьих не зависят от ошибок чисел с плавающей точкой.
