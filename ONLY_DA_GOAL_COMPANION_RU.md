# Совместный запуск Gambalator и Only_DA-Goal

Этот документ описывает минимальные изменения в отдельном проекте `Only_DA-Goal`, необходимые для совместного запуска с Gambalator. Код Gambalator при такой схеме не зависит от Only_DA-Goal и не изменяется.

## Результат

После настройки один файл `Only_DA-Goal/1.bat`:

- запускает Gambalator и Only_DA-Goal в одной консоли;
- проверяет, что локальные порты свободны;
- ждёт готовности обоих HTTP-сервисов;
- следит за обоими процессами;
- останавливает оба приложения по Ctrl+C;
- на Windows завершает всё дерево дочерних процессов при закрытии консоли;
- предоставляет короткий адрес `http://127.0.0.1:5000/gamba`, перенаправляющий в Gambalator.

OBS-виджет продолжает работать по адресу:

```text
http://127.0.0.1:5000/donationGoalRGG
```

Gambalator продолжает работать на внутреннем адресе:

```text
http://127.0.0.1:5741/
```

На этом этапе состояние донат-гола между несколькими открытыми браузерами автоматически не синхронизируется. Периодическое чтение общего состояния запланировано отдельным вторым этапом.

## Ожидаемое расположение каталогов

По умолчанию supervisor ищет каталог с именем `Gambalator` рядом с `Only_DA-Goal`:

```text
Общий каталог/
├── Gambalator/
│   ├── mise.toml
│   ├── package.json
│   ├── src/
│   └── backend/
└── Only_DA-Goal/
    ├── 1.bat
    ├── run_all.py
    └── start.py
```

Если каталог имеет другое имя или расположен в другом месте, перед запуском следует задать переменную окружения `GAMBALATOR_DIR`.

PowerShell:

```powershell
$env:GAMBALATOR_DIR = "D:\Programs\Gambalator"
& "C:\path\to\Only_DA-Goal\1.bat"
```

Command Prompt:

```bat
set "GAMBALATOR_DIR=D:\Programs\Gambalator"
C:\path\to\Only_DA-Goal\1.bat
```

## 1. Скопировать файлы launcher kit

Из каталога Gambalator:

```text
extras/only-da-goal/
```

нужно скопировать в корень отдельного проекта `Only_DA-Goal`:

- `run_all.py` — новый supervisor процессов;
- `1.bat` — замена старого launcher, ранее запускавшего только `start.py`.

`run_all.py` использует только стандартную библиотеку Python. Дополнительные Python-пакеты для supervisor не требуются.

## 2. Добавить короткий маршрут в `Only_DA-Goal/start.py`

В импорт Flask следует добавить `redirect`:

```python
from flask import Flask, jsonify, redirect, render_template, request
```

Рядом с остальными Flask-маршрутами следует добавить:

```python
@app.route('/gamba')
def gambalator():
    return redirect('http://127.0.0.1:5741/')
```

Маршрут только перенаправляет браузер. Он не запускает процесс и не передаёт данные между проектами. Запуском и остановкой занимается `run_all.py`.

Если используется нестандартный `GAMBALATOR_PORT`, адрес в маршруте также потребуется изменить. Переменная порта уже поддерживается supervisor и самим Gambalator, но старый `start.py` Only_DA-Goal не имеет общей конфигурации для построения redirect URL.

## 3. Предварительные требования

- Python, которым запускается `1.bat`, должен иметь зависимости Only_DA-Goal.
- Должен быть установлен `mise`, необходимый Gambalator.
- Gambalator должен содержать корректный `mise.toml`.
- Порты 5000 и 5741 либо выбранный `GAMBALATOR_PORT` должны быть свободны.
- При первом запуске без `node_modules` supervisor автоматически выполняет `mise run setup` в каталоге Gambalator.

Backend-зависимости Gambalator обрабатываются его существующей командой `mise run local` и `uv`.

## 4. Запуск и остановка

Запустить:

```text
Only_DA-Goal/1.bat
```

После готовности в общей консоли будут напечатаны адреса OBS goal и Gambalator. Вывод обоих приложений поступает в одну консоль и может перемешиваться.

Для нормальной остановки следует нажать Ctrl+C. Закрытие окна консоли на Windows также завершает дочерние процессы благодаря Job Object с флагом `KILL_ON_JOB_CLOSE`.

Если один из двух контролируемых процессов завершится, supervisor остановит второй и вернёт ненулевой код завершения. `1.bat` оставит сообщение об ошибке на экране.

## 5. Что supervisor проверяет

Перед запуском:

- существование каталога Gambalator;
- наличие команды `mise`;
- корректность `GAMBALATOR_PORT`;
- занятость портов Only_DA-Goal и Gambalator.

После запуска:

- Only_DA-Goal должен вернуть HTTP 200 с `/`;
- Gambalator должен вернуть HTTP 200 с `/api/health`;
- оба сервиса должны стать доступны в течение 180 секунд.

## 6. Что намеренно не включено

- код Only_DA-Goal не переносится внутрь Gambalator;
- Gambalator не читает `config.txt` или `token.txt` Only_DA-Goal;
- Only_DA-Goal не читает SQLite или `localStorage` Gambalator;
- DonationAlerts-интеграции проектов остаются независимыми;
- redirect не является reverse proxy: после перехода браузер показывает порт 5741;
- синхронизация отображения между Chrome и OBS будет реализована отдельно.

Такое разделение сохраняет минимальный объём изменений и позволяет удалить companion kit без миграции данных или изменения логики Gambalator.
