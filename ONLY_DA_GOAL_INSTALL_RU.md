# Подготовка Only_DA-Goal для совместного запуска с Gambalator

Эта инструкция описывает полный путь для пользователя Windows: скачать и установить
Gambalator, подготовить уже имеющийся Only_DA-Goal и запускать оба приложения через
один `1.bat`.

После подготовки:

- Gambalator получает донаты DonationAlerts и хранит состояние в SQLite;
- Only_DA-Goal показывает синхронизированную сумму в OBS;
- по умолчанию F6 рассчитывает один полный гамбашар, F7 — все доступные полные
  гамбашары; обе клавиши можно изменить в `start.py`;
- закрытие общей консоли останавливает оба приложения.

## 1. Разместить проекты рядом

Распакуйте Gambalator рядом с существующим Only_DA-Goal. Папка нового проекта должна
по умолчанию называться `Gambalator`:

```text
C:\StreamTools\
├── Gambalator\
└── Only_DA-Goal\
```

Если используется другое имя или расположение, его можно будет задать через
`GAMBALATOR_DIR`, как описано ниже.

## 2. Установить Gambalator

Сначала выполните разделы 1–4 документа
[WINDOWS_INSTALL_RU.md](./WINDOWS_INSTALL_RU.md). В кратком виде из папки Gambalator
нужно выполнить:

```powershell
cd "C:\StreamTools\Gambalator"
mise trust
mise install
mise run setup
mise run backend-setup
```

Для проверки можно один раз запустить `start-gambalator.cmd`, открыть
`http://127.0.0.1:5741/`, а затем остановить сервер через `Ctrl+C`. После подготовки
совместного запуска следует пользоваться общим `Only_DA-Goal\1.bat`.

## 3. Сделать резервную копию Only_DA-Goal

Перед изменениями откройте папку Only_DA-Goal в Проводнике. Создайте копии
`start.py` и `1.bat`, например `start.py.backup` и `1.bat.backup`. Это позволит
быстро вернуть рабочую версию, если при ручном переносе кода возникнет ошибка.

Файлы `templates\donationGoalRGG.html`, `token.txt`, `config.txt`, `static\image`,
`2.bat`, `info.txt` и `Test_Key_Value.py` комплект не заменяет. Старая WSS-интеграция
Only_DA-Goal остаётся без изменений.

## 4. Проверить комплект интеграции

Все файлы, которые нужны для подготовки, находятся в:

```text
Gambalator\extras\only-da-goal\
├── 1.bat
├── run_all.py
├── start.py
└── templates\
    └── donationGoalGambalator.html
```

Назначение файлов:

- `start.py` — образец, из которого нужно вручную перенести три отмеченных блока в
  свой `start.py`; целиком этот файл заменять не нужно;
- `1.bat` — запускает общий supervisor;
- `run_all.py` — запускает и останавливает оба дерева процессов;
- `donationGoalGambalator.html` — новый синхронизированный OBS-виджет.

## 5. Подготовить файлы Only_DA-Goal

Скопируйте файлы через Проводник:

1. `1.bat` — в корень Only_DA-Goal с заменой старого файла.
2. `run_all.py` — в корень Only_DA-Goal как новый файл.
3. `templates\donationGoalGambalator.html` — в существующую папку `templates`.

`start.py` из комплекта **не копируйте поверх своего файла**. Он служит образцом,
потому что пользовательский `start.py` может содержать собственные изменения.
Откройте оба файла рядом в текстовом редакторе и перенесите все три блока вместе с
начальным и конечным комментариями:

1. **Блок импортов** — от
   `ИМПОРТЫ ДЛЯ ИНТЕГРАЦИИ С GAMBALATOR: НАЧАЛО` до соответствующего комментария
   `КОНЕЦ`. Вставьте его в верхнюю часть пользовательского `start.py` рядом с
   остальными импортами. Он добавляет `redirect`, JSON, logging и локальные HTTP-
   запросы.
2. **Основной блок интеграции** — от
   `ИНТЕГРАЦИЯ С GAMBALATOR: НАЧАЛО` до соответствующего комментария `КОНЕЦ`.
   Вставьте его после исходной инициализации переменных и `middleValue`, но перед
   `if __name__ == "__main__":`. В этом блоке находятся адреса API, новые Flask-
   маршруты, получение суммы для OBS, запросы расчёта, F6/F7 и новый listener.
3. **Блок запуска горячих клавиш** — от
   `ЗАПУСК ГОРЯЧЕЙ КЛАВИШИ GAMBALATOR: НАЧАЛО` до соответствующего комментария
   `КОНЕЦ`. Вставьте его внутрь существующего `if __name__ == "__main__":` после
   запуска исходного `listener_thread` и до `app.run(...)`. Этот блок запускает
   отдельный listener для F6/F7.

Не переносите остальные части образца `start.py`: существующие методы, маршруты,
настройки и WSS-логику вашего Only_DA-Goal нужно сохранить как есть.

## 6. При необходимости изменить путь к Gambalator

Если проекты лежат рядом и папка называется `Gambalator`, ничего настраивать не
нужно. Для другого пути задайте переменную перед запуском:

```powershell
$env:GAMBALATOR_DIR = "D:\Programs\Gambalator"
cd "C:\StreamTools\Only_DA-Goal"
.\1.bat
```

Переменная действует в текущем окне PowerShell. Чтобы вернуться к пути по умолчанию,
закройте это окно или выполните:

```powershell
Remove-Item Env:GAMBALATOR_DIR
```

## 7. Запустить оба проекта

Откройте `Only_DA-Goal\1.bat` двойным щелчком либо выполните:

```powershell
cd "C:\StreamTools\Only_DA-Goal"
.\1.bat
```

Supervisor проверит окружение, при необходимости подготовит Gambalator, запустит оба
приложения и напечатает адреса:

```text
OBS sync:   http://127.0.0.1:5000/donationObsOverlay
OBS legacy: http://127.0.0.1:5000/donationGoalRGG
Gambalator: http://127.0.0.1:5741/
```

Не запускайте одновременно `start-gambalator.cmd` и общий `1.bat`: обе копии будут
пытаться занять порт `5741`.

## 8. Настроить Gambalator и OBS

1. Откройте `http://127.0.0.1:5741/`.
2. Подключите DonationAlerts в интерфейсе Gambalator.
3. В OBS создайте или откройте Browser Source.
4. Укажите URL `http://127.0.0.1:5000/donationObsOverlay`.
5. Отправьте тестовый донат или добавьте запись вручную и проверьте одинаковую сумму
   в Gambalator и OBS.
6. Нажмите F6 для расчёта одного раунда или F7 для расчёта всех доступных раундов.

Страница Gambalator не обязана оставаться открытой. Пока работает общая консоль,
backend получает донаты, глобальные клавиши выполняют расчёт, а OBS обновляет сумму.
`Ctrl+C` или закрытие консоли останавливает оба приложения.

## 9. Изображения и горячие клавиши

Виджет использует существующие изображения
`Only_DA-Goal\static\image\0.png`, `1.png`, `2.png` и далее. После изменения их
количества перезапустите `1.bat`.

Чтобы выбрать другие клавиши, запустите `2.bat` или
`python Test_Key_Value.py`. F6 и F7 — только стандартные значения, а не обязательные
клавиши. Затем измените в основном блоке интеграции `start.py` значения
`Key_gambalator_calculate_one` и `Key_gambalator_calculate_all`. Не используйте
F20/F21/F22, если нужно сохранить исходные действия Only_DA-Goal.

Подробное описание работы интеграции и адресов находится в
[ONLY_DA_GOAL_COMPANION_RU.md](./ONLY_DA_GOAL_COMPANION_RU.md).

## 10. Обновление комплекта

После получения новой версии Gambalator снова сравните файлы в
`extras\only-da-goal` со своей копией Only_DA-Goal. Если комплект изменился,
остановите общую консоль, сделайте свежую резервную копию и повторите шаг 5.
